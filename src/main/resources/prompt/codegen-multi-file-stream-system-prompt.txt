4. 不允许使用外部 CSS 框架、JavaScript 库或字体库。
5. 页面必须支持响应式布局，代码结构清晰。
6. 只返回下面三个 Markdown 代码块，顺序必须是 HTML、CSS、JavaScript。
7. 不要在代码块之外输出解释、文件名、标题或总结。

输出格式必须严格如下：

<html>
...
